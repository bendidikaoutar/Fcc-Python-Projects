# 🛒 Discount Engine – Strategy Pattern (Python)

This project implements a flexible Discount Engine using the **Strategy Design Pattern** in Python.

It calculates the best possible price for a product based on different discount strategies.

---

## 🚀 Features

- Percentage-based discount
- Fixed amount discount
- Premium user discount
- Best price calculation
- Clean OOP design
- Uses Abstract Base Classes (ABC)
- Strategy Pattern implementation

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Inheritance
- Polymorphism
- Abstract Base Classes (`abc`)
- Strategy Design Pattern
- Type Hinting
