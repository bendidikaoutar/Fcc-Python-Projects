# 💰 Budget App

A simple and practical Python budget management application that allows users to track deposits, withdrawals, and balances across different categories.

---

## 📌 Project Overview

The **Budget App** is a Python-based financial tracking system that helps manage money by organizing transactions into categories.

Each category maintains its own ledger and balance, making it easy to monitor income and expenses.

This project demonstrates:

- Object-Oriented Programming (OOP)
- Class design
- Data structures (lists & dictionaries)
- Basic financial logic implementation

---

## ⚙️ Features

✅ Create budget categories  
✅ Deposit money with descriptions  
✅ Withdraw funds with balance checking  
✅ Automatic balance calculation  
✅ Transaction history (ledger)  
✅ Transfer funds between categories
