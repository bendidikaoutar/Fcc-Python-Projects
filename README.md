📐 Polygon Area Calculator



An object-oriented Python project that models geometric shapes using classes and inheritance.



This application defines a Rectangle class and a Square class (which inherits from Rectangle) and provides methods to perform common geometric calculations and visual representations.



🧩 Project Overview



The goal of this project is to demonstrate:



Object-Oriented Programming (OOP)



Class inheritance



Method overriding



Encapsulation of logic inside objects



Clean class design and reusable methods



🏗 Classes Implemented

🔷 Rectangle



Initialize with width and height



Modify dimensions using setters



Compute:



Area



Perimeter



Diagonal length



Generate ASCII shape representation using \*



Calculate how many times another shape fits inside



Custom string representation



🔶 Square (Subclass of Rectangle)



Initialized with a single side



Ensures width and height always remain equal



Overrides rectangle setters



Adds set\_side() method



Custom string representation
